# 码道（CodeArts Doer）使用过程材料清单（codedao_proof/）

> **重要**：本目录只放**清单、命名规范与模板**。所有截图、控制台数据、时间线佐证必须由项目方在真实使用过程中导出，
> 严禁由助手合成、P图、编造或填写“已验证”。凡未提供的材料，一律保留为 `[待补]`。

## 一、四类材料清单

| 编号 | 材料 | 内容要求 | 交付格式 | 状态 |
|---|---|---|---|---|
| M1 | IDE 插件使用截图 | 码道插件在 IDE 中的真实使用界面（会话、生成、评审等），可辨认时间与项目 | png/jpg | `[待补]` |
| M2 | 码道控制台使用数据 | 控制台导出的真实统计（调用次数、项目数、活跃天数等），禁止手填 | png/jpg 或 pdf | `[待补]` |
| M3 | 真实界面截图 | 学生提交、AI 评价报告（含 `raw_total` 与校准说明）、教师复核、成长画像 | png/jpg | `[待补]` |
| M4 | 时间线佐证 | 关键提交记录、开发日志与对应码道会话时间线 | md/pdf | `[待补]` |

## 二、命名规范

```
codedao_<类别>_<序号>_<简述>.<ext>
```

| 类别代号 | 含义 | 示例 |
|---|---|---|
| `ide` | IDE 插件截图 | `codedao_ide_01_backend-agent-orchestration.png` |
| `console` | 码道控制台数据 | `codedao_console_01_monthly-usage.png` |
| `ui` | 系统界面截图 | `codedao_ui_01_student-submit.png` |
| `timeline` | 时间线与提交记录 | `codedao_timeline_01_git-log.md` |

要求：简述使用小写英文与连字符；序号从 01 递增；不得使用中文文件名以免跨平台解压乱码。

## 四、使用范围与责任边界

- **使用范围**：需求拆解与阶段计划、后端 Agent/RAG 与接口实现、前端门户与图表、测试与验收脚本、部署脚本与文档。
- **责任边界**：码道产出为代码、脚本与文档；评价分数、教师复核结论与统计结果全部来自系统真实运行数据。
- **禁止事项**：不得由助手生成或合成任何截图、控制台数据、时间线记录与“已验证”字样。
