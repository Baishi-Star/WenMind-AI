# 项目交付清单（project/）

本目录为**交付清单说明**，不复制源码副本，避免与仓库主副本产生差异。
打包交付时按本清单从仓库根目录取文件即可。

| 后端依赖 | `backend/requirements.txt` | Python 依赖清单 | 已在仓库 |
| 后端配置模板 | `backend/.env.example` | 环境变量示例，不含密钥 | 已在仓库 |

## 打包注意

- **禁止**将 `backend/.env`、任何密钥文件、`backup-*.json`、`skills-lock.json`、`.arts/`、`作文/`、`知识库 标准.docx` 放入交付包。
- 交付前执行一次 `pytest` 与前端 `npm run build`，确认门禁通过。
- 交付包中前端为 `dist/` 构建产物，后端为源码（或按流水线制品）。
