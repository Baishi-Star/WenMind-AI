# WenMind AI 交付说明（readme/ 派生版）

> 本节由根目录 `README.md` 派生，用于交付包内快速说明，口径与主 README 保持一致。

## 一、项目简介

WenMind AI（文思智评）是面向高中生、高中语文教师与系统管理员的 AI 个性化写作成长系统。
通过多 Agent 协同评价、写作知识库检索、评分证据追溯、学生申诉与教师复核、争议驱动的规则优化，
以及跨作文能力画像，构建“可解释、可质疑、可复核、可持续改进”的写作成长闭环。

- 三维评分：内容 content、表达 expression、发展 development，各 0–20；审题 topic 保留但不计分。
- 总分口径：60 分制总分按量规基准校准合成（非三维简单相加），公开校准前 `raw_total` 与校准参数。
- 双轨保存：AI 原始分与教师最终分分别存储、互不覆盖；教师复核会联动写入 `final_total_score`。
- 真实性边界：成长趋势与统计全部来自数据库真实评价点；少于 3 篇显示“数据积累中”，不使用随机数。

## 二、快速启动

Windows 推荐：双击根目录 `start.bat`（自动检查环境、安装依赖、启动前后端并打开首页）。

手动启动：

```bash
# 后端
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
cp .env.example .env
.venv/Scripts/python.exe -m uvicorn app.main:app --reload

# 前端
cd frontend
npm install
npm run dev
```

演示入口：`http://127.0.0.1:5173/`（首页）→ `/login`（角色一键登录）。
演示账号密码由后端 `.env` 的 `DEMO_PASSWORD` 提供，源码不硬编码凭据。

## 三、核心机制

| 机制 | 说明 |
|---|---|
| 多 Agent 评价 | 审题 → 内容 → 表达 → 发展 → 综合反馈 → 质量审核 → 证据核验 |
| 结构化校验 | Agent 输出经 Pydantic 校验；推理模型截断有兜底与重试预算提升 |
| 证据核验 | 精确位置通过、唯一匹配可修正、多匹配或不存在标 `unverified` |
| 总分校准 | `app/core/scoring.py` 单一事实来源，量规文案与代码同源 |
| 教师复核 | 双轨保存 + 六类争议归因 + 规则建议审批与量规版本回归发布 |
| 成长画像 | 复核优先、未复核标记、样本不足提示、跨量规版本差异提示 |

## 四、交付与部署

- 质量门禁：后端 `pytest`、前端 `npm run lint && npm run build`、接口契约比对、浏览器端到端。
- 部署布局：源码 `/opt/wenmind-src`，数据 `/opt/wenmind/data/`（不覆盖），后端 systemd `wenmind.service`
  （`EnvironmentFile=/opt/wenmind/env/wenmind.env`），前端 nginx `sites-enabled/wenmind.conf`，回滚 `deploy/rollback.sh`。
- 敏感信息：全部通过环境变量／密文参数注入，密钥只放后端 `.env`，禁止进入仓库、前端与日志。
- 答辩材料：见 `../ppt/`；码道使用留证清单见 `../codedao_proof/`（需项目方补充真实材料）。
